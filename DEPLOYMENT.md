# Размещение Admin Assist: GitHub + PythonAnywhere

GitHub хранит исходный код, PythonAnywhere запускает приложение и хранит общую базу. Отдельную браузерную версию делать не нужно. Локальный запуск через `start.bat` продолжает работать.

## 1. Аккаунты

Нужны аккаунты GitHub и PythonAnywhere. На [странице тарифов PythonAnywhere](https://www.pythonanywhere.com/pricing/) выберите **Create a Beginner account** — бесплатный план. Пароли и коды подтверждения вводите только на сайтах сервисов.

Инструкция ниже рассчитана на `www.pythonanywhere.com`. Если регистрируетесь на европейском сервисе, замените домен в `deploy/pythonanywhere_wsgi.py` на `eu.pythonanywhere.com`.

## 2. Код на GitHub

Создайте репозиторий `admin-assist` в своём аккаунте. Публикуйте содержимое только папки приложения, чтобы `app.py`, `wsgi.py`, `web/` и `README.md` были в корне репозитория.

Папку `data/`, файлы баз данных, резервные копии, пароли, токены и сам текст курсовой не загружайте. Нужные исключения уже перечислены в `.gitignore`. Учебные примеры создаются из кода при первом запуске.

Если репозиторий публичный, PythonAnywhere сможет скачать код без дополнительных ключей. Для закрытого репозитория проще загрузить подготовленный архив через **Files**; не вставляйте токены в адрес репозитория.

## 3. Перенос на PythonAnywhere

В **Consoles → Bash** выполните, подставив свой логин GitHub:

```bash
git clone https://github.com/YOUR_GITHUB_LOGIN/admin-assist.git ~/admin-assist
```

Альтернатива без Git: в папке локального приложения выполните `python tools/package_release.py`. Архив `admin-assist-deploy.zip` появится в родительской папке «курсовая». Загрузите его в домашнюю папку через **Files** на PythonAnywhere, затем выполните в **Bash**:

```bash
python3 -m zipfile -e ~/admin-assist-deploy.zip ~/
```

Архив содержит только код, интерфейс, проверки и инструкции. Локальная база в него не включается.

В обоих случаях файлы приложения должны оказаться в `/home/ВАШ_ЛОГИН/admin-assist/`, без дополнительной вложенной папки.

## 4. Создание сайта

1. Откройте **Web → Add a new web app**.
2. Выберите бесплатный адрес своего аккаунта, затем **Manual configuration**.
3. Выберите доступный Python версии **3.10 или новее**. Дополнительные библиотеки и виртуальное окружение не нужны.
4. В полях **Source code** и **Working directory** укажите `/home/ВАШ_ЛОГИН/admin-assist`.
5. Откройте ссылку **WSGI configuration file** в разделе **Code**.
6. Замените стандартное содержимое этого файла содержимым `deploy/pythonanywhere_wsgi.py` и сохраните. Логин аккаунта и домашняя папка определяются автоматически.
7. Включите **Force HTTPS** на странице **Web**, если настройка доступна.
8. Нажмите **Reload** и откройте `https://ВАШ_ЛОГИН.pythonanywhere.com`.

Не запускайте `python app.py` в консоли для публикации: это локальный сервер, а интернет-сайт на PythonAnywhere запускается через WSGI.

Файлы интерфейса уже раздаются приложением. Отдельные настройки **Static files** не требуются.

Официальные инструкции: [основы Web apps](https://help.pythonanywhere.com/pages/WebAppBasics), [базы данных](https://help.pythonanywhere.com/pages/KindsOfDatabases).

## 5. Данные публичного сайта

При первом открытии создаются 7 учебных обращений и 6 инструкций. База хранится вне папки с кодом:

```text
/home/ВАШ_ЛОГИН/.local/share/admin-assist/admin-assist.sqlite3
```

Обращения и расследования сохраняются между перезагрузками сайта. Повторная загрузка конфигурации не создаёт примеры заново и не очищает изменения. Локальный файл `data/admin-assist.sqlite3` не переносится.

Все посетители работают с одной учебной базой и могут создавать обращения, менять их статус и проходить расследования. На сайте есть соответствующая подпись. Это открытый стенд для демонстрации курсовой; используйте только вымышленные данные.

## 6. Проверка после публикации

1. Откройте сайт с телефона или в другом браузере, не подключённом к ноутбуку.
2. Создайте учебное обращение, начните расследование и ответьте на первую проверку.
3. Перезагрузите страницу — обращение и ответ должны сохраниться.
4. Нажмите **Reload** в PythonAnywhere и убедитесь, что запись осталась.
5. Проверьте базу знаний, смену статуса обращения и экспорт CSV.

Публичный адрес появляется только после создания и настройки сайта. Наличие кода на GitHub само по себе сайт не запускает.

## 7. Обновление и резервная копия

Для обновления кода из публичного репозитория в **Bash**:

```bash
git -C ~/admin-assist pull --ff-only
```

Затем нажмите **Reload** на странице **Web**. База находится вне репозитория и сохраняется.

Чтобы сделать согласованную копию SQLite, выполните в **Bash**:

```bash
python3 -c 'import sqlite3; from pathlib import Path; from datetime import datetime; p=Path.home()/".local/share/admin-assist"; source=sqlite3.connect(p/"admin-assist.sqlite3"); target=sqlite3.connect(p/("backup-"+datetime.now().strftime("%Y%m%d-%H%M%S")+".sqlite3")); source.backup(target); target.close(); source.close()'
```

Скачайте полученный файл через **Files**. Резервные копии не добавляйте в репозиторий.

У бесплатного сайта необходимо примерно раз в месяц продлевать срок работы кнопкой в разделе **Web**. Это не требует перехода на платный план. [Правила продления](https://blog.pythonanywhere.com/129/).
